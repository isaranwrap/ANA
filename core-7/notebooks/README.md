# Core-7 Notebook Scaffold

Each notebook in this folder is a lightweight template meant to be replaced with the full instructional content for the corresponding Core-7 module.

## How to Use

1. Open the notebook that matches your module.
2. Replace the placeholder headings, objectives, and outline with the finalized curriculum.
3. Implement the lesson using code cells, markdown explanations, and visualizations.
4. Ensure dependencies are documented in the module overview cell.

Feel free to duplicate an existing notebook if you add new modules to the program.
