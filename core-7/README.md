# Core-7 Curriculum Scaffolding

This directory contains the initial scaffolding for the Core-7 notebooks and related website pages. Each module ships with a placeholder notebook and page so contributors can focus on filling in rich content without worrying about the base structure.

- `notebooks/` – Jupyter notebook shells for each Core-7 module.
- `website/` – Content pages that mirror the notebook outline for use on the public site.

Add or adjust module names as the curriculum evolves.
