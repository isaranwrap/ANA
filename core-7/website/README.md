# Core-7 Website Content Scaffold

The markdown files inside `pages/` provide a parallel structure for the public-facing Core-7 curriculum website. They mirror the notebook layout so web editors can translate the technical material into accessible copy.

## Editing Workflow

1. Draft the technical walkthrough in the matching notebook.
2. Summarize key insights, highlights, and calls to action in the corresponding page file.
3. Convert the markdown into the format your site generator requires when publishing.

Add supporting assets (images, diagrams, downloadable resources) in subdirectories as needed.
